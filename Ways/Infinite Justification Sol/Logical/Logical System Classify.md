# Ways to classify logical systems:

--- check this

### By Nature of Logical Principles
1. **Classical vs. Non-Classical Logic**
   - Classical Logic
   - Non-Classical Logics (e.g., Intuitionistic Logic, Modal Logic)

### By Number of Truth Values
1. **Two-Valued (Bivalent) Logic**
2. **Multi-Valued Logic**
   - Three-Valued Logic
   - n-Valued Logic
   - Fuzzy Logic (continuous range of truth values between 0 and 1)

### By Type of Semantics
1. **Truth-Functional Semantics**
2. **Kripke Semantics (for Modal and Intuitionistic Logics)**
3. **Algebraic Semantics**
4. **Game-Theoretic Semantics**
5. **Topological Semantics**

### By Deductive System
1. **Hilbert Systems**
2. **Natural Deduction Systems**
3. **Sequent Calculus**
4. **Tableau Methods**
5. **Resolution Calculus**

### By Expressive Power
1. **Propositional Logic**
2. **First-Order Logic (Predicate Logic)**
3. **Second-Order Logic**
4. **Higher-Order Logics**

### By Modalities
1. **Alethic Modal Logic (necessity and possibility)**
2. **Deontic Logic (obligation, permission)**
3. **Epistemic Logic (knowledge, belief)**
4. **Temporal Logic (time-related modalities)**
5. **Dynamic Logic (actions and programs)**

### By Structural Rules
1. **Substructural Logics**
   - Linear Logic
   - Relevance Logic
   - Affine Logic
   - Lambek Calculus

### By Handling of Negation
1. **Classical Negation**
2. **Intuitionistic Negation**
3. **Paraconsistent Logic (handling contradictions)**

### By Use of Quantifiers
1. **Quantifier-Free Logics**
2. **First-Order Logics (with quantifiers for individuals)**
3. **Higher-Order Logics (with quantifiers for predicates, functions)**

### By Proof Theoretic Properties
1. **Consistency**
2. **Completeness**
3. **Soundness**
4. **Decidability**
5. **Compactness**

### By Philosophical Foundation
1. **Constructivist Logics**
   - Intuitionistic Logic
   - Constructive Type Theory
2. **Realist/Platonist Logics**
   - Classical Logic

### By Computational Properties
1. **Decidable Logics**
2. **Undecidable Logics**
3. **NP-Complete Logics**
4. **PSPACE-Complete Logics**

### By Use in Applications
1. **Mathematical Logic**
2. **Philosophical Logic**
3. **Computer Science Logic**
   - Logic Programming
   - Automated Theorem Proving
   - Constraint Logic Programming

### By Extensions and Restrictions
1. **Extensions**
   - Modal Logic
   - Temporal Logic
   - Dynamic Logic
2. **Restrictions**
   - Propositional Logic (restricted from Predicate Logic)
   - Finite Model Theory

### By Treatment of Truth
1. **Classical Logic (true/false)**
2. **Fuzzy Logic (degrees of truth)**
3. **Probabilistic Logic (probabilities of truth)**
4. **Paraconsistent Logic (tolerates inconsistencies)**

### By Model Theory
1. **Standard Model Theory**
2. **Non-Standard Model Theory**
3. **Finite Model Theory**

### By Logical Constants and Operations
1. **Standard Logical Operations (AND, OR, NOT, IMPLIES)**
2. **Non-Standard Operations (e.g., in Many-Valued Logics)**

### By Interpretations
1. **Classical Interpretations**
2. **Intuitionistic Interpretations**
3. **Modal Interpretations**
4. **Algebraic Interpretations**

### By Metalogical Properties
1. **Reflexivity**
2. **Symmetry**
3. **Transitivity**
