### **9. Formal Systems and Validity**

#### **1. Formal Systems**

A **formal system** is a structured set of rules and symbols used to construct proofs and reason about logical statements. It typically consists of:

- **Syntax**: The formal language used, including symbols, rules for constructing well-formed formulas, and expressions.
- **Semantics**: The meaning or interpretation of these symbols and formulas.
- **Inference Rules**: Rules that dictate how one can derive conclusions from premises.
- **Axioms**: Basic statements or assumptions taken to be true without proof.

**Example**:
- In propositional logic, the formal system includes symbols like \( \land \), \( \lor \), \( \to \), and \( \neg \), along with rules like Modus Ponens.

#### **2. Validity**

**Validity** refers to whether an argument's conclusion logically follows from its premises. An argument is valid if and only if there is no possible situation where the premises are true and the conclusion is false.

- **Valid Argument**: If the premises are true, the conclusion must be true.
- **Invalid Argument**: It is possible for the premises to be true while the conclusion is false.

**Example**:
- **Argument**: **"If it rains, the ground will be wet. It is raining. Therefore, the ground is wet."**
  - **Premise 1**: \( P \to Q \) (If it rains, then the ground will be wet)
  - **Premise 2**: \( P \) (It is raining)
  - **Conclusion**: \( Q \) (The ground is wet)
  - This argument is valid because, given the premises, the conclusion logically follows.

#### **3. Proof Techniques in Formal Systems**

To show that an argument is valid within a formal system, you can use various proof techniques:

- **Direct Proof**: Construct a proof directly from the premises.
- **Proof by Contradiction**: Assume the negation of the conclusion and show that it leads to a contradiction.
- **Proof by Induction**: Use induction to prove statements about integers or other well-defined sets.

**Example of Proof by Induction**:
- **Statement**: **"The sum of the first \( n \) positive integers is \( \frac{n(n+1)}{2} \)."**
- **Proof**:
  1. **Base Case**: For \( n = 1 \), the sum is \( 1 \) and \( \frac{1(1+1)}{2} = 1 \), so the base case holds.
  2. **Inductive Step**: Assume the statement is true for \( n = k \). Prove it for \( n = k + 1 \):
     - Sum of the first \( k + 1 \) integers: \( \frac{k(k+1)}{2} + (k + 1) \)
     - Simplify to \( \frac{k^2 + 3k + 2}{2} = \frac{(k + 1)(k + 2)}{2} \)
     - Hence, the formula holds for \( n = k + 1 \).

#### **4. Consistency and Completeness**

- **Consistency**: A formal system is consistent if it does not lead to contradictions. That is, it is not possible to prove both a statement and its negation.
- **Completeness**: A formal system is complete if every statement that is true in the system's semantics can be proven within the system.

**Example**:
- **Consistency**: Propositional logic is consistent because it is impossible to derive both a statement and its negation from its axioms and inference rules.
- **Completeness**: Propositional logic is complete because every statement that is true in all models (semantically valid) can be proven using its axioms and rules.
