* **Law of Non-Contradiction**
\[
\forall A \, \neg (A \wedge \neg A)

* **Law of Excluded Middle (Three Value Version)**
\[
\forall A \, (A \vee \neg A)
\]
9. The three valued version of the logical law of excluded middle, states that if something has a definite truth value or not undefined, then it must either true or false at the same instance in the same sense and not both. In other words, if something is definitely true at the same instance in the same sense, then it is impossible for it to be false; if something is definitely false at the same instance in the same sense, then it is impossible for it to be true. [Definition]
    * *This imply a three valued logic: true, false, and undefined.*
    * If A is true, then A is not false.
    * If A is false, then A is not true.
    * If A is undefined, then A is undefined.
10. If something has a definite truth value or not undefined, and it is both true and false at the same instance in the same sense, then it means violation of the logical law of identity and law of non-contradiction. [5,6]
11. If something violates the law of excluded middle (three valued version), then it means violation of the logical law of identity and law of non-contradiction. [10,9]
    - It follows from the **Law of Identity** alone also, because at the same instance in the same sense, if \(A\) is what it is, then it must either hold or not hold, with no third option. 
12. If something violates the law of excluded middle (three valued version), then it is impossible for it to be true or right. [11,8] [11,4]. For example:

      * Either the statement "2 + 2 equals 4" is true, or it is false; not both, if it has a definite truth value or not undefined.

\[
\forall A \forall B \forall C \, ((A = B \wedge B = C) \rightarrow A = C)
\]
13. Law of Transitivity of Identity states that **if \(A\) means (is identical to) \(B\), and \(B\) means (is identical to) \(C\), then \(A\) means (must be identical to) \(C\)** in the same context or meaning. [Definition]

\forall A \forall B \, (A = B \rightarrow B = A)
