# Fulfillment

## Is fulfillment Truly Good and a Must? 

## Definition

* Something is **necessary (Must, should, etc.)**, if and only if it cannot be otherwise if the otherwise will imply wrongness or contradiction. 
* On this meditation, X is **fulfilled**, if and only if, X is having supreme felicity or having supreme happiness.
  
## Logical Reasoning

1. Fulfillment means absolute or supreme happiness, satisfaction, etc. [Implication]
2. If happiness is inherently good, then more happiness means more good and much more the absolute or supreme happiness. [Implication]
3. Therefore, If happiness is inherently good, then fulfillment is better (more good). [1,2]
4. Therefore, If I must engage in a right and truly good behavior, then should I strive for fulfillment? [3]
