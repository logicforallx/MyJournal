## **Conjunction (A ∧ B)**  

For any sentences "\( \mathcal{A} \) and \( \mathcal{B} \) and so on" is true if and only if both \( \mathcal{A} \) and \( \mathcal{B} \) and so on are true. Otherwise, it is false.

| A | B | A ∧ B |
|---|---|-------|
| T | T | T     |
| T | F | F     |
| F | T | F     |
| F | F | F     |

 
Why is this the case?

1. **Conjunction (Definition):**
   * In grammar, a **conjunction** is a word (such as 'and', 'but', 'while', or 'although') that joins together other words or groups of words. It is similar to: co-occurrence, concurrence, coexistence, or concurrence of assertion, and the like.
   * In logic, a **conjunction** ($\mathcal{A} \land \mathcal{B} \land \dots$) is a compound proposition and it is asserting that **all its component propositions** joined together by ('$\land$', 'and', 'plus', etc.) are true (in accordance with fact or reality). For instance:
     * Let’s say $X$ is a triangle, $X$ has 3 sides, and $X$ is not a circle ($\mathcal{A} \land \mathcal{B} \land \neg C$). This means the following assertions:
       * "X is a triangle ($\mathcal{A}$)" is true.
       * "X has 3 sides ($\mathcal{B}$)" is true.
       * "X is not a circle ($\neg C$)" is true.
   * Unlike natural-language "and" (which may imply causality, contrast, or sequence), a logical conjunction is **truth-functional**: its meaning depends *only* on
2. The assertion is true, if and only if it is actually true—i.e., it is truly in accordance with fact or reality, and not just asserted as true. *By [Definition]*
3. Therefore, the sentence/assertion "$\mathcal{A} \land \mathcal{B} \land \dots$" is true, if and only if each of its components is actually true: $\mathcal{A}$ is actually true, $\mathcal{B}$ is actually true, and so on. *Base from [1,2]*
4. Therefore, the sentence/assertion "$\mathcal{A} \land \mathcal{B} \land \dots$" is false, if 
 at least one of its components is false (not actually true). For example, if $\mathcal{A}$ is false (not actually true), but $\mathcal{B}$ is true, and so on, the conjunction as a whole is false. *Base from [1,2]*
5. Therefore, for conjunction, for any sentence "$\mathcal{A}$ and $\mathcal{B}$, and so on," the statement is true if and only if both $\mathcal{A}$ and $\mathcal{B}$ and so on are true. Otherwise, it is false. *Base from [3,4]*

*Note that the truth value for \( A \land B\) is always the same as the truth value for \( B \land A\), base on the definition of logical conjunction. Connectives that have this property are called commutative.*

## **Disjunction (A ∨ B)**  

Recall that ‘V’ always represents inclusive or. So, for any sentences $A$ and $B$, is true if and only if either 
$A$ or $B$ is true. We can summarize this in the characteristic truth table for disjunction:

(True if at least one is true)
| A | B | A ∨ B |
|---|---|-------|
| T | T | T     |
| T | F | T     |
| F | T | T     |
| F | F | F     |

Why is this the case?

1. **Disjunction (Definition):**
    * A **disjunction** is the relationship between two distinct alternatives. It is a statement expressing the relationship between two distinct alternatives (especially one using the word “or”).
    * In logic, a **disjunction** ($\mathcal{A} \lor \mathcal{B} \lor \dots$) is a compound proposition and it is asserting that **at least one of its component propositions** joined together by ('$\lor$', 'or', etc.) is true (in accordance with fact or reality). For instance:
     * Let’s say Ant is black, Ant is red, or Ant is green ($\mathcal{A} \lor \mathcal{B} \lor C$). This means that at least one of the following is true:
        * Ant is black ($A$)
        * Ant is red ($B$)
        * Ant is green ($C$)
2. The assertion is true, if and only if it is actually true—i.e., it is truly in accordance with fact or reality, and not just asserted as true. *By [Definition]*
3. Therefore, for disjunction, for any sentences $A$ and $B$, is true if and only if either $A$ or $B$ is true. (True if at least one is true). *Base from [1,2]*

        * Truth tables aim to represent **all logically possible assignments**
        * Each sentence letter can independently be T or F
        * Every value of each letter that combined with every value of the others are logically possible (It is available and no logical contradiction)
        * Therefore, every value of each letter must be combined with every value of the others

            * But those assignments are logically possible
            * Therefore the table is incomplete
            * Therefore it fails its purpose
