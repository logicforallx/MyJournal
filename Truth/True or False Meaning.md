# True or False Meaning

##  What do I mean by true or false?

1. True means in accordance with fact or reality in the same context or meaning. It is what it is. If my beliefs, statements, etc are true, then it means it must reflect the fact or reality of it. For example:
   * Triangle has a side is true, if it is in accordance with the actual existing (real) meaning of it, which is a plane figure with three straight sides and three angles.
   * Bachelor is unmarried man is true, if it is in accordance with the actual existing (real) meaning of it, which is a man who is not and has never been married.
   * 2 is greater than 1 in general arithmetic context is true,  if it is in accordance with the actual existing (real) implication of it.

2. False means not in accordance with fact or reality in the same context or meaning. It is not what it is. If my beliefs, statements, etc are false, then it means it does not reflect the fact or reality of it. For example:
   * Existing is nothing is false, if it is not in accordance with the actual existing (real) meaning of it, which is something that is there.
   * Happiness is a bad state or feeling is false, if it is not in accordance with the actual existing (real) meaning of it, which is good state or feeling.
   * Parallel lines that intersect are false, if it is not in accordance with the actual existing (real) meaning of it, which is lines that never intersect, and they form the same angle when they cross another line.

3. Right means true or correct as a fact. So right means in accordance with fact or reality in the same context or meaning, as a fact. [1]

4. Fact means a thing that is known or proved to be true. So true means in accordance with a thing that is known or proved to be true, and false is the otherwise of that. [1,2]

5. Reality means the state or quality of having actual or true existence rather than the notional idea of them. So true means in accordance with the state or quality of having actual or true existence rather than the notional idea of them and false is the otherwise of that. [1,2]

6. Truth means the quality or state of being true. So truth means the quality or state of being in accordance with fact or reality in the same context or meaning, not the otherwise of it. [1,2]

**But why do I mean true or false as that?** This is because of the following:

1. **Logical Law of Identity:** This logical law means that each thing is identical with itself in the same context or meaning. This is self-evidently true as justification is in itself or its meaning. It is what it is, for example:
   * 5 is the same as 5
   * 1 + 1 is the same as 2
   * A is the same as A
   * Tree is the same as tree
   * Existing is the same as the continued presence of something.
   * The mountain peak is the same as the highest point on the mountain.
   * The building in the city center is the same as the central building in the city.

2. **Logical Law of Non-Contradiction** This logical law means that it is impossible for each thing to be not identical with itself at the same instance in the same sense, context, or meaning. This is because, each thing is identical with itself in the same context or meaning, as we can see above. For example:
   * 100 = 3 is impossible in the same sense of fundamental counting.
   * A is not A is impossible in the same sense.
   * Tree is not a tree is impossible in the same sense of the word.

3. **Therefore**, each reality or a fact is identical with itself in the same context or meaning. Also, it is impossible for each reality or a fact to be not identical with itself at the same instance in the same sense, context, or meaning. [1,2]

4. Identical with itself in the same context or meaning is being consistent with or in agreement with something, and not identical with itself at the same instance in the same sense, context, or meaning is not being consistent with or in agreement with something. Those are true by implication of it.

5. "In accordance" means being consistent with or in agreement with. This is true by definition.

6. **Therefore,** each reality or a fact must be in accordance with itself in the same context or meaning. Also, it is impossible for each reality or a fact to be not in accordance with itself at the same instance in the same sense, context, or meaning.  [3,4,5]

7. **Therefore**, If I want to know what's real or factual, then is it helpful to use the above meaning of true as in accordance with fact or reality in the same context or meaning, or false as not in accordance with fact or reality in the same context or meaning? [6]
