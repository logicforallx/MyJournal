# Plantinga’s Modal Ontological Argument

## Intro

Alvin Plantinga's ontological argument, as presented in his book *"The Nature of Necessity" (1974)*, is expressed in his own formalized way. This version includes Plantinga's emphasis on the modal framework, particularly the use of **possible worlds** and the **axiom S5** of modal logic, which states that if something is possibly necessary, then it is necessary. 

## **Plantinga’s Modal Ontological Argument with Possible Justification**

**Here is the argument in Plantinga's original terms:**

1. A being has **maximal excellence** in a given possible world \( W \) if and only if it is omnipotent, omniscient, and wholly good in \( W \).  
   - This is possibly because, power is excelent and all powerful is the maximal of it, plus knowledgable is excelent and all knowing is the maximal of it, plus extremely good is excelent and wholly good is the maximal of it. So maximal excellence requires all powerful (omnipotent), all knowing (omniscient), wholly good.

2. A being has **maximal greatness** if it has maximal excellence in **every** possible world. 
   - This is possibly because, a being that has maximal excellence in every possible world has more greatness than the otherwise. In other words, a being that is omnipotent, omniscient, wholly good, etc in every possible world is greater than the otherwise.

3. It is possible that there is a being that has maximal greatness. *(Premise)*  
   - Alvin Plantinga believes that the possibility of a maximally great being is reasonable because no contradiction can be demonstrated in the concept of such a being. At this stage of his argument, he is not asserting that a maximally great being actually exists. He is only asserting that it is possible, which is enough for the modal ontological argument to proceed.
   - This is also possibly because, it does not have inherent logical contradiction, like maried bachelor, square circle, triangle without side, etc. No inherent logical contradiction or no contradiction on its  meaning itself means theres a chance that it exist, which means it is possible.

4. Therefore, there is a possible world \( W \) in which a being exists that has maximal greatness.  
   - This is base from 3.

5. A being has maximal greatness only if it exists in every possible world.  
   - This is base from 1 and 2. 

6. Therefore, that being that exists in \( W \) exists in every possible world.  
   - This is base from 4 and 5.

7. Therefore, a maximally great being exists in the actual world.
   - This is base from 6.

8. Therefore, a maximally great being exists.
   - This is reiteration of 7.

**Another Christian philosopher, William Lane Craig, characterizes Plantinga's argument in a slightly different way:**

1. It is possible that a maximally great being exists.
2. If it is possible that a maximally great being exists, then a maximally great being exists in some possible world.
3. If a maximally great being exists in some possible world, then it exists in every possible world.
4. If a maximally great being exists in every possible world, then it exists in the actual world.
5. If a maximally great being exists in the actual world, then a maximally great being exists.
6. Therefore, a maximally great being exists.

## Critical Clarification

- **Possible Worlds**: In modal logic, a "possible world" includes a way reality could have been. Plantinga’s argument says if God exists in any possible world (a logically coherent scenario), then God must exist in all of them, including ours.
