# Charles Hartshorne


## Intro

Charles Hartshorne's **Ontological Argument** is a **20th-century** development of Anselm's argument and modal logic. Hartshorne's version builds on the idea of God's **necessary existence** and argues that if the concept of God is logically coherent, then God's existence as a necessary being must occur in reality. 

- **Primary Source**: *The Logic of Perfection*, Chapter 2 (“Ten Ontological or Modal Proofs for God’s Existence”).
- **Key Passage**:  
  > *"What the Ontological Proof does is to show that there is a being (God) such that, in order to affirm that it is possible, one must, if one is consistent, admit that it is actual. For the only way God can be possible is by being actual."* (p. 50)


## Possible Argument Structure

1. God is defined as a being that exists necessarily (i.e., if God exists, God exists necessarily). (G → □G)

2. Therefore, either God necessarily exists or God necessarily does not exist. (□G ∨ □¬G)

3. It is possible that God exists (i.e., God's existence is not impossible). (◇G)

4. If it is possible that God exists, then God's existence is not necessarily non-existent. (◇G → ¬□¬G)

5. From 2 and 4: Since God's existence is possible (◇G), then ¬□¬G, which together with □G ∨ □¬G entails □G.

6. Therefore, God necessarily exists. (□G)

7. Therefore, God actually exists. (G)
