# Leibniz's ontological argument

## Intro

Leibniz believed that Descartes' ontological argument was incomplete because it did not assert the coherence of a "supremely perfect being". Leibniz reasoned that all perfections can exist together in a single entity.

Here is a formal breakdown of the **exact** argument from Leibniz, presented as a series of logical premises and conclusions. This structure can be found primarily in **his "Theodicy" (1710)**, where Leibniz refines and makes explicit the key steps of his ontological argument.

## **Leibniz's Ontological Argument with Possible Justification**

1. **God is a being having all perfections.** (Definition)

2. **A perfection is a simple and absolute property.** (Definition)

3. **Existence is a perfection.**
   - Existence is considered a property that adds to a being's greatness, which makes it a perfection.
   - This is also because, if a being does not exist, then it cannot have identity at all, which means it cannot have at least greatness at all, which means it cannot have perfection at all.

4. **If existence is part of the essence of a thing (i.e., God base from 1,2,3), then it is a necessary being.**
   - Leibniz argues that for a being whose essence entails existence, this being must be necessary (i.e., it cannot fail to exist).

5. **If it is possible for a necessary being (i.e., God base from 4) to exist, then a necessary being (God) does exist.**
   - Leibniz posits that if it is possible for such a necessary being to exist (which, based on his other premises, is conceivable), it follows that it must exist.
   - This is also because, a necessary being means a being that cannot fail to exist.
   - This is also because, if its possible for a necessary being to exist, then it exist in all possible worlds as it is a being that cannot fail to exist, by definition. If something exist in all possible worlds, then it must exist in the actual world.

6. **It is possible for a being to have all perfections.**
   - Leibniz claims that it is **possible** for a being to possess all perfections, because perfection by definition entails the ability to possess the greatest possible set of qualities, and thus such a being is **logically** possible.
   - Furthermore, this can be because of the following:
      1. Perfection means a simple and absolute property. [Definition]
      2. Absolute property means property that is completely free from faults or defects. [Definition]
      3. If property is completely free from faults or defects, then it has no imperfection at all sense. [1,2]
      4. If property has no imperfection at all sense, then it has no logical contradiction at all sense. *For contradiction is imperfection by the laws of logic (ie. law of non contradiction).* [Implication]
      5. If property has no logical contradiction at all sense, then it is not only logically possible but it is also logically necessary at all sense. *For If property has truly no logical contradiction at all sense, then it is consistent at all sense, for if its not consistent at all sense, then it has contradiction, which is contradiction for non contradiction at all sense, which is logically impossible.  If property is consistent at all sense, then it is not only possible but necessarily true at all sense, as true means in accordance with facts or reality.* [Implication]
      6. Therefore, it is impossible for perfection to be not logically possible at all sense, as it is logically necessary. [1,2,3,4,5] For instance:
         - All good, all powerful, all knowing, etc (if included in perfection) cannot be imperfect or not logically possible in any sense or circumstances. For all sense or circumstances implies logically possible sense or circumstances, because not logical is logically impossible to be true sense or circumstances.
      7. Therefore, it is logically possible for a being to have all perfections, by logical necessity of its meaning. [6]

7. **Therefore, a necessary being (God) does exist.**
   - From all these premises, Leibniz concludes that a necessary being, possessing all perfections (i.e., God), **must exist**.
